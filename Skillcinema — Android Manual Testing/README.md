# Skillcinema — Android Manual Testing

## 📱 О проекте

**Skillcinema** — мобильное Android-приложение для поиска информации о фильмах и сериалах.

В рамках проекта было проведено тестирование MVP-версии приложения, включая:

- анализ требований;
- проверку пользовательского интерфейса;
- дымовое тестирование (Smoke Testing);
- функциональное тестирование основных экранов;
- оформление тестовой документации;
- регистрацию дефектов;
- подготовку итогового отчёта о тестировании.

### Рекомендация по релизу

По итогам дымового тестирования приложение **не рекомендуется** к демонстрации заказчику.

**Причины:**

- выполнено 8 smoke-тестов;
- выявлено 8 дефектов;
- часть функциональности не работает;
- некоторые экраны не открываются;
- обнаружены критичные визуальные ошибки, влияющие на пользовательский опыт.
