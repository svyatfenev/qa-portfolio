Skillcinema — Android Manual Testing
О проекте

Skillcinema — мобильное Android-приложение для поиска информации о фильмах и сериалах.

В рамках проекта было проведено тестирование MVP-версии приложения, включая анализ требований, проверку пользовательского интерфейса, дымовое и функциональное тестирование основных экранов приложения, а также оформление тестовой документации и баг-репортов.

Используемые инструменты
Android Studio
Android Emulator
Google Sheets
YouTrack
