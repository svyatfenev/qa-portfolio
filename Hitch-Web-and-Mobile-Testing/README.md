# Hitch — Manual QA Portfolio Project

## О проекте

Hitch — учебный проект по ручному тестированию веб-сервиса для поиска сотрудников и размещения анкет кандидатов.

В рамках проекта было проведено комплексное тестирование пользовательских сценариев, включая регистрацию и авторизацию пользователей, работу личных кабинетов кандидата и компании, функциональность отправки предложений о работе, главную страницу сервиса, а также регрессионное, дымовое и кросс-браузерное тестирование.

Во время работы были подготовлены тестовые артефакты, оформлены баг-репорты в YouTrack, составлены матрица трассировки, тестовые отчёты и проведено кросс-ревью тестовой документации.

### Примечание

Полное кросс-браузерное тестирование выполнить не удалось из-за завершения доступа к тестовому стенду. Для проверки был выбран браузер Safari как второй по популярности в мире. В ходе тестирования были выявлены те же дефекты, что и в Google Chrome, за исключением невозможности авторизации через аккаунт, зарегистрированный в Google Chrome.
