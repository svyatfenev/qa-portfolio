# Skillcinema — Mobile Non-Functional Testing

## 📱 О проекте

**Skillcinema** — Android-приложение для поиска информации о фильмах и сериалах.

В рамках данного этапа разработки было проведено нефункциональное тестирование приложения, включающее проверку пользовательского опыта (UX), сетевого взаимодействия и поведения приложения при различных уровнях заряда батареи.

---

# 🛠 Используемые инструменты

- Android Studio
- Android Emulator
- Android Emulator Extended Controls
- Google Sheets
- YouGile

---

# 📋 Выполненные работы

## 1. UX Testing

Проведено UX-тестирование мобильного приложения.

Во время тестирования проверены:

- удобство навигации;
- логичность пользовательских сценариев;
- понятность интерфейса;
- доступность основных функций;
- последовательность переходов между экранами;
- соответствие интерфейса требованиям и макетам.

## 2. Network Testing

Проведено тестирование работы приложения при различных сетевых условиях.

Проверены:

- загрузка данных при стабильном подключении;
- работа приложения при медленном соединении (3G);
- обработка отключения сети;
- отображение сообщений об ошибках;
- восстановление работы после появления сети.

## 3. Battery Testing

Проведено тестирование приложения при различных уровнях заряда аккумулятора.

Проверены:

- работа приложения при высоком уровне заряда;
- работа при среднем уровне заряда;
- работа при низком уровне заряда;
- работа при критическом уровне заряда;
- устойчивость приложения;
- корректность выполнения фоновых процессов.
